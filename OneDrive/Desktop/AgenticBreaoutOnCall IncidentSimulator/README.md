3. **Canlı Slack / Discord Bildirim Entegrasyonu:** Test ve kurulum süreçlerini karmaşıklaştırmadan doğrudan mobil ekran deneyimine odaklanabilmek için harici bildirim servisleri entegre edilmemiştir.
